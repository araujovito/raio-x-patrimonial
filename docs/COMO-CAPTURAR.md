# Como capturar as imagens do README

Salve os arquivos nesta pasta com estes nomes exatos:

| Arquivo | O que capturar |
| --- | --- |
| `explorador.png` | A seção "Explore os deputados": lista, busca e filtros visíveis |
| `perfil.png` | O painel do perfil: foto, gráfico de evolução e composição patrimonial |
| `interacao.gif` | (opcional) Uma busca, a troca de um filtro e um clique num ponto do gráfico |

## No Windows

- **Print de área:** `Win + Shift + S`, selecione a área, cole no Paint e salve como PNG.
- **GIF:** use a Xbox Game Bar (`Win + G`) para gravar um vídeo curto e converta,
  ou uma ferramenta como o ScreenToGif.

Dicas: use a janela larga (desktop), evite capturar dados pessoais do navegador
e prefira imagens com menos de 1 MB.
